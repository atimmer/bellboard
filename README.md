# Bellboard

Bellboard is a small static soundboard for bell sound effects. It uses plain
HTML, CSS, and JavaScript so it can be hosted directly on GitHub Pages.

## Sounds

- **Town Square Bell** uses `assets/audio/community-bell.mp3`.
- **Crystal Chime** uses `assets/audio/clear-bell-chime.mp3`.

## Local use

Open `index.html` in a browser, or serve the folder with any static file server.
There is no build step.

## Deployment

The site is intended for GitHub Pages from the repository's default branch.
